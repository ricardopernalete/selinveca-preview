# Selinveca — Vista previa

Snapshot estático y **autocontenido** de la página principal de [selinveca.com](https://selinveca.com) (Selinveca Formación).

- `index.html` — HTML único con CSS, imágenes y fuentes embebidas (base64). No requiere internet ni dependencias.
- `preview.png` — captura de referencia.

## Ver

- Abre `index.html` directamente en el navegador, o
- Si GitHub Pages está activado: **https://ricardopernalete.github.io/selinveca-preview/**

> Es una copia visual (sin JavaScript), por lo que el menú móvil y los acordeones no son interactivos.
